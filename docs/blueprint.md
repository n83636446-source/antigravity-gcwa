# **App Name**: StockPilot

## Core Features:

- Inventory Tracking: Real-time tracking of stock levels for each product.
- Product Management: Add, edit, and remove products with details like name, description, price, and supplier.
- Supplier Management: Maintain a database of suppliers with contact information and supply history.
- Stock Alerts: Receive notifications when stock levels fall below a specified threshold.  Uses generative AI as a tool to estimate expected need.
- Reporting and Analytics: Generate reports on stock levels, sales trends, and inventory turnover rates.

## Style Guidelines:

- Primary color: Deep blue (#2E4057) for a professional and trustworthy feel.
- Background color: Light gray (#E7E9EB) for a clean and modern look.
- Accent color: Teal (#34A7A7) to highlight important actions and information.
- Body and headline font: 'Inter', a sans-serif font, will be used.
- Use simple, line-based icons to represent different stock management actions.
- A clean and organized layout with clear sections for each feature will provide user efficiency.
- Subtle transitions and animations will enhance user experience during stock level updates and report generation.
